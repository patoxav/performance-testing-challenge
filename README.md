# performance-testing-challenge

## Arquetipo de k6

Este repositorio incluye un arquetipo listo para usar para ejecutar pruebas
de performance con [k6](https://k6.io/) y generar informes/reportes con las
capacidades nativas de la herramienta (HTML, JSON y consola).

Ver [`k6/README.md`](k6/README.md) para más detalles sobre estructura, uso y
cómo crear nuevas pruebas.
